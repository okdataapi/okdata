# 小红书蒲公英关键词搜索指数 API

> 关键词在小红书上最近约三个月（时间范围由平台定）的逐日搜索指数，带每天的相关笔记数、曝光、阅读和互动。搜索指数是平台的度量，不是搜索次数。

网页版：https://okdata.online/zh/apis/xiaohongshu/pgy/keywords/history/

- **接口**：`GET /v1/xiaohongshu/pgy/keywords/history`
- **ID**：`xiaohongshu.pgy.keywords.history`
- **价格**：$0.04/次
- **返回**：一个 KeywordHistory 对象（`data.item`）
- **状态**：预览
- **适合**：热点研究、内容调研

## 价格

每次调用 $0.04，返回一个结果。查 1,000 次共 $40.00。失败的调用不扣费。

## 参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `keyword` | string | 是 |  | 一个关键词。（例：`面膜`） |
| `view` | string: compact / standard / full | 否 | `standard` | 返回多少字段。full 会在 ext 里带上平台特有字段。 |
| `fields` | string[] | 否 |  | 只保留这些字段，按路径写（如 author.name），用来省 token。放在查询参数里时用逗号分隔。 |

cursor、view、fields 的用法见 [请求说明](https://okdata.online/zh/docs/requests/)。

## 返回字段

每一条都是一个 [KeywordHistory](https://okdata.online/zh/docs/objects/keyword_history/)。

| 字段 | 类型 | 说明 |
|---|---|---|
| `keyword` | string | 关键词。 |
| `points` | KeywordPoint[] | 逐日数据，一天一条，从早到晚。 |
| `ext` | object | 平台特有字段，只在 view=full 时返回。 |

### Python

```python
import os
import requests

resp = requests.get(
    "https://api.okdata.online/v1/xiaohongshu/pgy/keywords/history",
    headers={"Authorization": f"Bearer {os.environ['OKDATA_API_KEY']}"},
    params={"keyword": "面膜"},
    timeout=60,
)
body = resp.json()
if body["code"] != "ok":
    raise RuntimeError(f"{body['code']}: {body['message']} (charged: {body['charged']})")

row = body["data"]["item"]
print(row)
print("cost: $" + body["meta"]["billing"]["amount"])
```

## 错误

所有错误同一种结构：code、request_id、message 和 message_zh（每个 code 一句固定的话）、charged、retry、retry_after_seconds、param 和 docs_url，具体问题写在 problems 里。错误不扣费；只有 settlement_unknown 的扣费结果要查询后才知道。完整列表：https://okdata.online/zh/docs/errors/

## 常见问题

### 小红书蒲公英关键词搜索指数接口多少钱？

每次调用 $0.04，返回一个结果。查 1,000 次共 $40.00。失败的调用不扣费。

### 需要小红书账号、Cookie 或扫码登录吗？

不需要。只要带上 okdata 的 API key。返回的是小红书上的公开数据，不会用到你自己的小红书账号。

### 调用失败会扣费吗？

不会。所有错误都会返回 charged: false；只有超时返回 charged: null，表示结果还没确定。带同一个 Idempotency-Key 重发，绝不会重复扣费。

### 小红书不展示某个字段怎么办？

这个字段会是 null，meta.unavailable 里会列出它和原因：platform（平台本来就不展示）或 capability（我们暂时取不到）。
