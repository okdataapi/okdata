# Google 广告透明中心 API

> 广告主和他们在搜索、YouTube、展示广告上的广告。

网页版：https://okdata.online/zh/apis/google/

2 个接口，每次 $0.004 到 $0.004。地区：海外。不需要Google 广告透明中心账号或 Cookie。

| 接口 | ID | 返回 | 价格 |
|---|---|---|---|
| [Google 广告透明中心广告主搜索](https://okdata.online/zh/apis/google/advertisers/search/) | `google.advertisers.search` | Advertiser[] | $0.004/次 · 每页约 10 个广告主 |
| [Google 广告主的广告](https://okdata.online/zh/apis/google/advertisers/ads/list/) | `google.advertisers.ads.list` | Ad[] | $0.004/次 · 每页约 40 条广告 |

## 适合做什么

- 广告情报: `google.advertisers.search`, `google.advertisers.ads.list`
- 竞品监控: `google.advertisers.ads.list`
