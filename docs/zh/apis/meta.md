# Meta 广告库 API

> Facebook 和 Instagram 上在投的广告，按关键词或广告主查。

网页版：https://okdata.online/zh/apis/meta/

3 个接口，每次 $0.004 到 $0.004。地区：海外。不需要Meta 广告库账号或 Cookie。

| 接口 | ID | 返回 | 价格 |
|---|---|---|---|
| [Meta 广告库搜索](https://okdata.online/zh/apis/meta/ads/search/) | `meta.ads.search` | Ad[] | $0.004/次 · 每页约 30 条广告 |
| [Meta 广告详情](https://okdata.online/zh/apis/meta/ads/get/) | `meta.ads.get` | Ad | $0.004/次 |
| [Meta 广告主的广告](https://okdata.online/zh/apis/meta/advertisers/ads/list/) | `meta.advertisers.ads.list` | Ad[] | $0.004/次 · 每页约 30 条广告 |

## 适合做什么

- 广告情报: `meta.ads.search`, `meta.ads.get`, `meta.advertisers.ads.list`
- 竞品监控: `meta.ads.search`, `meta.ads.get`, `meta.advertisers.ads.list`
