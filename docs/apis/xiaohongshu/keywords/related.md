# Xiaohongshu search suggestions API

> What Xiaohongshu’s search box suggests as a keyword is typed, in its order, about 10 at a time. Words and places only, no index.

Canonical page: https://okdata.online/apis/xiaohongshu/keywords/related/

- **Endpoint**: `GET /v1/xiaohongshu/keywords/related`
- **ID**: `xiaohongshu.keywords.related`
- **Price**: $0.02 per call · about 10 results per page
- **Returns**: a page of about 10 results (`data.items`, KeywordRelated objects)
- **Status**: preview
- **Good for**: Trend research, Content research

## Price

One call costs $0.02 and returns one page of about 10 results. Collecting 1,000 results takes about 100 calls, $2.00 in total. Each page is a separate call; failed calls are not charged.

## Parameters

| Name | Type | Required | Default | Description |
|---|---|---|---|---|
| `keyword` | string | yes |  | One keyword. (e.g. `露营`) |
| `view` | string: compact / standard / full | no | `standard` | How much of each object comes back. full adds platform-specific fields under ext. |
| `fields` | string[] | no |  | Fields to keep, by path (author.name), to save tokens. In a query string: comma-separated. |

cursor, view and fields work as described in [Requests](https://okdata.online/docs/requests/).

## Returned fields

Each item is a [KeywordRelated](https://okdata.online/docs/objects/keyword_related/).

| Field | Type | Description |
|---|---|---|
| `keyword` | string | The related keyword. |
| `related_to` | string | The keyword asked about. |
| `relation` | string \| null | How it relates: searched together (query), appears together in content (posts), searched before (prior) or after (after), or suggested as you type (suggestion). |
| `rank` | integer \| null | Position among the keywords of the same relation, from 1. |
| `relevance` | number \| null | How closely it is related, 0 to 1. |
| `search_index` | integer \| null | Its search index (the platform's measure, not a count); null where the platform gives none. |
| `composite_index` | integer \| null | Its composite index (the platform's measure of attention, not a count). |
| `ext` | object | Platform-specific extras. Only returned with view=full. |

## Request examples

### cURL

```bash
curl -G "https://api.okdata.online/v1/xiaohongshu/keywords/related" \
  -H "Authorization: Bearer $OKDATA_API_KEY" \
  --data-urlencode 'keyword=露营'
```

### Python

```python
import os
import requests

resp = requests.get(
    "https://api.okdata.online/v1/xiaohongshu/keywords/related",
    headers={"Authorization": f"Bearer {os.environ['OKDATA_API_KEY']}"},
    params={"keyword": "露营"},
    timeout=60,
)
body = resp.json()
if body["code"] != "ok":
    raise RuntimeError(f"{body['code']}: {body['message']} (charged: {body['charged']})")

for row in body["data"]["items"]:
    print(row)
print("cost: $" + body["meta"]["billing"]["amount"])
```

### TypeScript

```ts
const url = new URL('https://api.okdata.online/v1/xiaohongshu/keywords/related');
url.searchParams.set('keyword', "露营");

const res = await fetch(url, {

    Authorization: `Bearer ${process.env.OKDATA_API_KEY}`,
  },

for (const row of body.data.items) {
  console.log(row);
}
console.log('cost: $' + body.meta.billing.amount);
```

## Errors

Errors share one shape: code, request_id, message and message_zh (a fixed sentence per code), charged, retry, retry_after_seconds, param and docs_url, with the specifics in problems. They are not charged; only settlement_unknown is unknown until looked up. The full table: https://okdata.online/docs/errors/

## Questions

### How much does the Xiaohongshu search suggestions API cost?

One call costs $0.02 and returns one page of about 10 results. Collecting 1,000 results takes about 100 calls, $2.00 in total. Each page is a separate call; failed calls are not charged.

### How do I get the next page?

Pass page.next_cursor from the response back as the cursor parameter. When page.has_more is false there is nothing left. Every page is its own call at $0.02.

### Do I need a Xiaohongshu (RedNote) account, cookies or a QR login?

No. You send only your okdata API key. The data is public data from Xiaohongshu (RedNote); nothing is fetched with your own Xiaohongshu (RedNote) account.

### Am I charged when a call fails?

No. Every error response says charged: false, except a timeout, which says charged: null until the outcome is known. Resend with the same Idempotency-Key and you are never charged twice.

### What if Xiaohongshu (RedNote) does not show a field?

The field is null, and meta.unavailable names it with the reason: platform (the platform never shows it) or capability (we cannot fetch it yet).
